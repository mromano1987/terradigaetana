# Terra di Gaetana

Shopify-Shop für sizilianisches Olivenöl (Olio Extravergine) – `t1p04c-vh.myshopify.com`, Theme „Horizon“.

## Marke

| Rolle | Farbe |
|---|---|
| Hintergrund (Creme) | `#F7F2E9` |
| Text (Dunkelbraun) | `#2B2620` |
| Olivgrün (Logo) | `#7A8C4C` |
| Olivgrün dunkel (Buttons, Akzente) | `#5F7039` |
| Salbei (Blätter) | `#C5C9AA` |
| Creme dunkel (Flächen) | `#EFE8DA` |

Schriften (Shopify-Fontbibliothek): Überschriften **Cormorant**, Fließtext **Jost**.

`brand/` enthält das Original-Logo und daraus freigestellte PNGs (Schriftzug, komplettes Logo, Porträt, Ranke).
Die Dateien liegen auch im Shopify-Admin unter *Inhalte → Dateien* (`terradigaetana-*.png`).

## Theme

`theme/` spiegelt die angepassten Dateien des unveröffentlichten Themes „Terra di Gaetana – Entwurf“.
Änderungen werden per Admin-API (`themeFilesUpsert`) eingespielt; der Theme-Editor kann diese Dateien überschreiben.
